快速开始

1

配置 API

右键点击扩展图标 → 选项，或点击弹窗中的"设置"按钮，进入设置页面配置你的 AI 服务商和 API Key。

2

选择模型

在设置页面选择要使用的 AI 模型，支持多种主流模型，如 DeepSeek、Qwen、GPT 等。

3

开始使用

打开任意包含表单的网页，点击扩展图标 → "一键智能填写"，或使用快捷键即可自动填充表单。

📝

使用方法

⚡

一键填写

点击扩展图标后，点击"一键智能填写"按钮，AI 会自动识别页面上的所有表单字段并填充合适的测试数据。

🎯

单字段填写

将鼠标悬停在输入框上，点击出现的闪电按钮，可单独为该字段生成数据。

⌨️

快捷键

使用 Ctrl+Shift+L (Mac: ⌘+Shift+L) 快速触发一键填写功能。

🔄

重新生成

对填充结果不满意？再次点击填写按钮，AI 会生成全新的数据。

常见问题

Q 为什么点击填写后没有反应？
A

请检查以下几点：

  • 确保已正确配置 API Key
  • 点击"测试连接"确认 API 可用
  • 刷新当前页面后重试
  • 某些页面可能不支持（如 chrome:// 页面）
Q 生成的数据不符合预期怎么办？
A

可以尝试：

  • 再次点击填写按钮重新生成
  • 使用单字段填写功能针对特定字段生成
  • 调整 Temperature 参数（设置页面），数值越高生成越随机
  • 尝试更换其他 AI 模型
Q API 调用失败怎么办？
A

常见原因和解决方案：

  • API Key 错误：检查是否复制完整
  • 余额不足：检查 API 账户余额
  • 网络问题：检查网络连接，国外 API 可能需要代理
  • 模型不可用：尝试更换其他模型
Q 如何修改快捷键？
A

在浏览器中打开 chrome://extensions/shortcuts，找到 AutoFormX，即可自定义快捷键。
